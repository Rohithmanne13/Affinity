# Resume Description

## Personalized Content Ranking & Recommendation Platform
*Python, Apache Spark, PyTorch, XGBoost, MLflow, FastAPI, Docker*

- Built an end-to-end personalized content recommendation pipeline using **Apache Spark** to process user interactions and generate behavioral, content and contextual features.
- Developed **user segmentation and multi-source candidate-generation pipelines**, followed by XGBoost-based and neural ranking models for personalized Top-K content recommendation.
- Evaluated ranking models using **Precision@K, Recall@K and NDCG@K**, with MLflow for experiment tracking, model versioning and artifact management.
- Deployed the recommendation system through a **Dockerized FastAPI service**, implementing cold-start handling and diversity/freshness-aware Top-K recommendation.
